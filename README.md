Descrição do sistema:  
O que o sistema faz ?  
Vende produtos destinado à Pets;

Quem utilizará o sistema?  
Pessoas interessadas em produtos de Pet;

Qual problema ele resolve ?  
Facilita a compra de produtos, onde o usuário não corre risco de ir a uma loja e não encontrar o produto desejado;

Cadastro de usuario  
Login  
Fluxo do carrinho (adicionar, consultar e excluir)
Gestão de estoque  
Validação de pagamento
